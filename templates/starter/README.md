# My App

An Appverse app: plain HTML, CSS and JavaScript that runs in a sandbox with no network access.

    applet dev      run it in the browser sandbox, reloading when you save
    applet check    look for mistakes
    applet pack     build my-app.applet

Before you share it, change `id` in `manifest.json` to your own (the reverse of a domain you own, such as `com.mystudio.myapp`):
the id names the storage slot. Documentation: https://appverse.lol/make.html
